# Kofty Icons

Adds the Kofty logo to `.kfy` files in VS Code.

## Usage

Install the extension, then activate the theme:

Command Palette → `Preferences: File Icon Theme` → **Kofty Icons**.

Only `.kfy` and `.is` files get the Kofty logo.
Everything else keeps the default VS Code icon theme.
